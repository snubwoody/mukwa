# Contributing to Mukwa

This document describes the process of contributing to Mukwa. It is intended for anyone considering opening an issue,
discussion or pull request. For people who are interested in developing Mukwa and technical details behind it, please
check out our "Developing Mukwa" document as well.

## Bug reports

To report a bug open a ["Bug reports"](https://github.com/snubwoody/mukwa/discussions/categories/bug-reports) discussion
and make sure to include a detailed description the bug and of how to reproduce it.

Check the [issue tracker](https://github.com/snubwoody/mukwa/issues?q=is%3Aissue%20state%3Aopen%20label%3Abug) to see if
it is already a well-known bug, or check the "Bug reports" discussions to see if the bug has already been reported.

## Feature requests

Like bug reports, first search through both issues and discussions and try to find if your feature has already been
requested. Otherwise, open a discussion in the
["Feature requests and ideas"](https://github.com/snubwoody/mukwa/discussions/categories/feature-requests-and-ideas)
category.

## AI policy

AI generated code, discussions and comments are not permitted.
